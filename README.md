# Intelifive website

Static corporate website for [intelifive.com](https://intelifive.com/), served from the repository root with GitHub Pages. No build step, external fonts, analytics, cookies or browser JavaScript.

## Local review

Open `index.html` directly in a browser. Relative stylesheet, favicon and page links support local files as well as GitHub Pages. No server or Node installation is required to view or host the site.

## Pages

- Homepage: corporate identity and approach.
- Careers: opportunity overview.
- Founding CEO: responsibilities, governance, proposed equity and pre-funding terms.

## Before publication

- Review all public copy and finalized role terms.
- Configure and verify receipt and replies for careers@intelifive.com, including sender identity. Delivery remains unverified.
- Complete the legal engagement assessment before work commences; this website does not approve unpaid employment.
- Supply verified legal disclosures and applicant privacy information appropriate to the actual entity and data controller. Incorporation and controller details have not been supplied.
- Confirm Pages deployment branch, custom domain and HTTPS settings.

## SEO

Rendered semantic HTML, unique titles and descriptions, canonicals, social metadata, sitemap and robots.txt are included. Organization and WebSite structured data use the public brand without asserting incorporation. JobPosting markup is omitted pending finalized legal relationship and eligibility. Legacy content and bundled assets have been removed; old URLs return a custom 404.
